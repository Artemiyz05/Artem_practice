# Система учета заявок на ремонт бытовой техники (BytService)
Информационная система для автоматизации процессов приема, обработки и контроля выполнения заявок на ремонт бытовой техники. Проект разработан для компании ООО «БытСервис».
# Основные возможности:
- Многопользовательский доступ: Разграничение прав доступа для четырех ролей: Клиент, Оператор, Мастер и Менеджер
- Полный жизненный цикл заявки: От создания и назначения мастера до отслеживания статуса и формирования статистики.
- Безопасность: Реализована система авторизации, защита от SQL-инъекций через параметризованные запросы и встроенная капча для защиты от ботов.
- Надежность данных: Механизмы регулярного резервного копирования критически важной информации.
# Технологический стек:
- Язык программирования: C# (.NET)
- Интерфейс: Windows Forms
- База данных: MS SQL Server (использование SqlClient)
- Тестирование: Unit-тесты (MSTest)
- Проектирование: UML (диаграммы прецедентов, активностей и последовательностей)
# Архитектура и проектирование:
В проекте реализован системный подход к разработке программного обеспечения:
- Анализ и проектирование: Созданы UML-диаграммы для визуализации бизнес-процессов и взаимодействия компонентов системы.
- Паттерны проектирования: Для работы с базой данных использован паттерн Singleton, обеспечивающий единую точку доступа к БД через класс Database
- Модульность: Логика взаимодействия с БД вынесена в отдельную библиотеку классов DatabaseController, что упрощает поддержку и тестирование кода.
# Качество и тестирование:
- Модульное тестирование: Реализованы тесты для базовых операций с данными (вставка, получение скалярных значений, удаление).
- Валидация: Внедрена проверка входных данных на уровне интерфейса (использование ComboBox для исключения ошибок ввода) и на уровне логики приложения.
- Тест-кейсы: Разработаны подробные сценарии тестирования для проверки авторизации и функционала сортировки заявок.
# Структура проекта
- DatabaseController/ — библиотека для работы с базой данных (Singleton, параметризованные запросы).
- UnitTestProject1/ — проект с юнит-тестами.
- Practice_Нечеухин/ — основной проект приложения (формы, логика, капча).
- Documentation/ — техническое задание и пояснительные материалы.
